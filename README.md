# Tic Tac Toe Game 🎮
Play the classic **Tic Tac Toe game** right in your browser! Built with **HTML, CSS, and JavaScript**, this interactive game lets two players challenge each other, shows the winner, and even lets you restart anytime. Simple, fun, and perfect for practicing web development skills.

## Features ✨
- Two-player gameplay (Player X vs Player O)
- Simple, clean, and responsive design
- Game status updates: shows current player and winner
- Option to restart the game at any time
- Built entirely with **vanilla JavaScript** (no external libraries)


## How to Play 🕹️
1. Players take turns to mark a cell with **X** or **O**.
2. The first player to get **3 marks in a row** (horizontally, vertically, or diagonally) wins.
3. If all cells are filled without a winner, the game ends in a **draw**.
4. Click **Restart** to play again.

## Technologies Used 🛠️
- HTML5
- CSS3
- JavaScript (ES6)
- VS Code for development
